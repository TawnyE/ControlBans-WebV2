Troubleshooting

Common issues and how to fix them.

Plugin Won't Start

"Unsupported class file version"

ControlBans requires Java 21+. Check with java -version and update if needed.

"Cannot load locales/ja.yml" or "Cannot load locales/ru.yml"

This was a bug in versions before 5.8. Update to v5.9+ and delete the affected files — fresh copies will be extracted from the JAR.

"Locale en.yml is missing keys" spamming the console

Bug in versions before 5.8. Update to v5.9+.

Punishment Issues

Banned players can still join

The player's UUID may not match. On offline-mode servers, UUIDs are computed from the username. If you switched between online and offline mode, old bans may be under the wrong UUID. Unban and re-ban the player.

Muted players can still chat

  • The player may have controlbans.bypass.chat permission.
  • On multi-server networks, the mute cache may not have propagated. Wait a few seconds or have the player rejoin.
  • Using SQLite on a multi-server network? Switch to MySQL so all servers share the database.

"/check says No punishment found with that ID"

Bug in versions before 5.8 where short usernames were mistaken for punishment IDs. Update to v5.9+.

Players see "Player '<player>' is already banned" with literal text

Bug in versions before 5.8. Update to v5.9+.

"/ipban says Player not found but the player is online"

The player's IP is on the local/private blocklist (127.x, 10.x, 192.168.x). IP banning is blocked for safety. In v5.9+, you'll see a clear message about this.

Display Issues

Raw color codes showing in chat

Bug in versions before 5.8 where MiniMessage tags weren't parsed in the freeze command. Update to v5.9+.

Messages appearing 2-3 times on Velocity

Bug in versions before 5.9. Update to v5.9+ on both your proxy and backends.

Banlist/mutelist showing duplicate entries

Bug in versions before 5.8. Update to v5.9+.

Velocity / BungeeCord Issues

"Your server did not send a forwarding request to the proxy"

The Velocity forwarding secret doesn't match. See the Velocity Setup guide.

Staff on other servers don't see alerts

Bug in versions before 5.9. Update to v5.9+.

Punishments don't sync across servers

All backends must use the same database. Switch from SQLite to MySQL or PostgreSQL.

Database Issues

Connection fails

  • Is the database host reachable from the Minecraft server?
  • Are the credentials correct?
  • Does the database user have CREATE, INSERT, UPDATE, DELETE, SELECT permissions?

Want to start fresh

This deletes all punishment data

There is no undo.

# Clear all punishments for a specific player
/controlbans database clear Connor

# Clear ALL punishments
/controlbans database clear-all
