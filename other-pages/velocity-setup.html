Velocity Proxy Setup

This guide walks you through setting up ControlBans on a Velocity proxy network. Once configured, punishments issued on any backend server will broadcast across your entire network, and banned players will be kicked from the proxy itself.

What you need

A Velocity proxy server, one or more Paper backend servers, and the ControlBans JAR.

Step 1: Install Velocity

  1. Download Velocity from papermc.io/downloads/velocity.
  2. Create a folder for your proxy (e.g. velocity/).
  3. Put velocity.jar inside it.
  4. Run it once to generate the default config: java -jar velocity.jar

Velocity will create velocity.toml and a forwarding.secret file, then shut down.

Step 2: Configure Velocity

Open velocity.toml and set these values:

# The port players connect to
bind = "0.0.0.0:25577"

# Set to false for cracked/offline accounts, true for premium only
online-mode = false

# This is critical — tells Velocity to forward player IPs and UUIDs to backends
player-info-forwarding-mode = "modern"

Scroll down to the [servers] section and add your backend servers:

[servers]
survival = "127.0.0.1:25565"
creative = "127.0.0.1:25566"

# The first server in this list is where new players land
try = [
    "survival"
]

Step 3: Configure Your Backend Servers

On each Paper backend, you need to enable Velocity forwarding.

server.properties

online-mode=false

paper-global.yml

Open config/paper-global.yml and find the proxies section:

proxies:
  velocity:
    enabled: true
    online-mode: false
    secret: 'YOUR_FORWARDING_SECRET_HERE'
Where do I find the secret?

Open the forwarding.secret file in your Velocity folder. Copy the entire contents and paste it between the quotes in the secret field. The secret must be identical on Velocity and every backend.

Step 4: Install ControlBans

Put the ControlBans.jar file in the plugins/ folder of every server:

  • Your Velocity proxy's plugins/ folder
  • Each backend server's plugins/ folder

Step 5: Start Everything

  1. Backend servers first (survival, creative, etc.)
  2. Velocity proxy last

You should see this in the Velocity console:

[controlbans]: ControlBans Velocity extension enabled (Internal).

Step 6: Test It

Connect to your Velocity proxy (port 25577 by default) and run:

/ban Connor test ban

Connor should get kicked from the entire network, and the ban broadcast should appear on all servers.

Shared Database (Required for Multi-Server)

For punishments to sync across servers, all backends must use the same database:

database:
  type: mysql
  host: your-database-host
  port: 3306
  name: controlbans
  username: your-username
  password: your-password
Don't use SQLite for networks

If you use SQLite, each backend will have its own separate punishment database and punishments won't sync. You must use MySQL, PostgreSQL, or MongoDB for multi-server setups.

Common Issues

"Your server did not send a forwarding request to the proxy"

The Velocity secret doesn't match between your proxy and backend. Double-check that the secret in paper-global.yml matches the contents of forwarding.secret on Velocity.

Players see punishment messages 2-3 times

Make sure you're running ControlBans v5.9 or later. Earlier versions had a bug where the proxy rebroadcast to players who already received the message from their backend.
