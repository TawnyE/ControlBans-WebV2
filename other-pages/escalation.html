Escalation System

ControlBans can automatically escalate punishments for repeat offenders. The first time a player breaks a rule, they get a light punishment. The second time, a harsher one. You define the escalation ladder in your config.

Templates (Recommended)

Templates are predefined punishment presets that staff can apply with a #hashtag. Each template has numbered levels that automatically escalate based on the player's prior offense count.

Using a Template

# Via the punishment GUI
/punish Connor

# Via direct command with a hashtag
/ban Connor #Hacking
/mute Connor #Swearing
/punish Connor #Griefing

How Escalation Works

hacking:
  type: "any"
  display-name: "#Hacking"
  levels:
    window-days: 30
    1: "TEMPBAN 7d"    # 1st offense
    2: "BAN"           # 2nd offense
    3: "IPBAN"         # 3rd offense

If a player has 0 prior #Hacking punishments, they get level 1. If they have 1 prior, they get level 2. And so on.

Clamping

If a player has more priors than the highest configured level, they get the highest level. The system never produces an out-of-range punishment.

Level Format

FormatExampleResult
TYPE DURATIONTEMPBAN 7d7-day tempban
TYPEBANPermanent ban
DURATION7d7-day temp version of base type
permanentpermanentPermanent version of base type

Supported Types

BAN, TEMPBAN, IPBAN, TEMPIPBAN, MUTE, TEMPMUTE, IPMUTE, TEMPIPMUTE, VOICEMUTE, TEMPVOICEMUTE, WARN, KICK

Creating a Custom Template

my-custom-rule:
  type: "mute"
  display-name: "#My-Custom-Rule"
  description: "Describe what this is for"
  item: "ORANGE_CANDLE"
  reason: "Auto-fill reason text"
  keywords:
    - "my keyword"
  levels:
    window-days: 30
    1: "WARN"
    2: "TEMPMUTE 1h"
    3: "TEMPMUTE 1d"
    4: "MUTE"

After editing, run /controlbans reload.

Keyword Matching

By default, ControlBans matches prior offenses by #hashtag. For free-form reasons, enable keyword matching:

templates:
  match-by-keywords: true

When enabled, previous punishments with matching keywords in the reason count as priors.

Standalone Escalation

Separate from templates, there's a standalone escalation system for /tempban and /tempmute without hashtags:

escalation:
  enabled: true
  window-days: 90
  levels:
    default:
      1: 1d
      2: 7d
      3: 30d
      4: permanent
    "Hacking":
      1: 7d
      2: 30d
      3: permanent
